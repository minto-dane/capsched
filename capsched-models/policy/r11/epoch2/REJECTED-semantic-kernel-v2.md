# Semantic Kernel v2 Rejected

The exact local draft:

```text
semantic-kernel-contract-schema-v2.json
f30bf42e28a527904d0663feec7e34dc3494c7708169d0f3741fa2d0b4ae13ad

semantic-kernel-contract-v2.json
a70489bf816569f382268d69e23e147a0319b7c0370717cc1367f3b1834f8c8a
```

is retained unchanged. Three local hostile reviews rejected it before a
reference interpreter was built. It lists syntax requirements but lacks an
independent mathematical denotation, mixes pre-candidate and candidate gates,
and does not close assurance or scenario/composition semantics.

See ADR-0018, Analysis 0215, and Validation 0304. Successor work uses a v3
denotational contract; v2 cannot authorize K0/G0, candidate IR, TLA+, or model
support.
